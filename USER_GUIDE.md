# Metka — руководство пользователя

**Metka** — веб-сервис для заметок с цветными тегами. Записывайте мысли, задачи и идеи, помечайте их тегами и быстро находите нужное — по тегу или по тексту.

- Репозиторий: https://github.com/Maslo1911/Metka
- Онлайн-версия: https://metka.onrender.com *(адрес появится после деплоя, см. [раздел «Деплой»](#деплой-на-бесплатном-хостинге))*
- Документация API (Swagger): `<адрес сервиса>/docs`

> ℹ️ Сервис размещён на бесплатном тарифе Render: если сайтом долго не пользовались, он «засыпает», и первое открытие занимает 30–60 секунд. Просто подождите — дальше всё работает быстро.

## 1. Регистрация и вход

При первом открытии сайта появляется форма с двумя вкладками: **Вход** и **Регистрация**.

**Регистрация**
1. Откройте вкладку **Регистрация**.
2. Заполните поля:
   - **Имя** — как к вам обращаться (до 100 символов);
   - **Логин** — от 3 до 50 символов, должен быть уникальным;
   - **Пароль** — не короче 6 символов. Значок 👁 справа показывает/скрывает пароль.
3. Нажмите **Зарегистрироваться** — вы сразу попадёте в приложение.

**Вход**
1. На вкладке **Вход** введите логин и пароль.
2. Нажмите **Войти**.

Сессия сохраняется в браузере на 24 часа — повторно входить не нужно. Когда срок истечёт, приложение само вернёт вас на экран входа.

## 2. Главный экран

| Элемент | Что делает |
|---|---|
| Логотип **Metka** (слева) | Сбрасывает поиск и фильтр, показывает все заметки |
| Строка **«Поиск по тексту заметок»** | Мгновенный поиск по названию и тексту |
| Кнопка **+ Новая заметка** | Открывает форму создания заметки |
| Кружок с инициалами (справа) | Меню профиля: имя, логин, выход, админ-панель (для админа) |
| Строка **Теги** | Фильтр: **Все · N** и по одному чипу на каждый тег |
| Кнопка **Управление** (пунктир, со значком тега) | Переход на экран управления тегами |
| Карточки заметок | Название, начало текста, теги и дата. Клик — открыть заметку |

## 3. Создание заметки

1. Нажмите **+ Новая заметка**.
2. Введите **Название** (обязательно) и текст заметки.
3. Чтобы добавить теги, нажмите **Добавить тег** и отметьте один или несколько тегов из списка.
   Нужного тега нет? Нажмите **Создать тег**, введите имя, выберите цвет — новый тег сразу прикрепится к заметке.
4. Нажмите **Сохранить**. Заметка появится в начале списка на главном экране.

Чтобы вернуться без сохранения, нажмите **← Все заметки** в верхней панели.

## 4. Редактирование и удаление заметки

- **Открыть:** кликните по карточке на главном экране.
- **Изменить:** правьте название и текст прямо на странице; добавляйте теги кнопкой **Добавить тег**, убирайте — крестиком ✕ на чипе тега. Нажмите **Сохранить**.
  Внизу страницы видно состояние: «Есть несохранённые изменения» или «Все изменения сохранены».
- **Удалить:** значок корзины 🗑 в верхней панели → подтвердите удаление. Удалённую заметку восстановить нельзя.

## 5. Поиск и фильтрация

- **По тексту:** начните вводить слово в строку поиска — список фильтруется на лету, регистр букв не важен.
- **По тегу:** нажмите на чип тега в строке **Теги**. Будут показаны только заметки с этим тегом. **Все · N** снимает фильтр.
- Поиск и фильтр работают **одновременно**: например, тег «работа» + слово «отчёт».

## 6. Управление тегами

Откройте экран кнопкой **Управление** в строке тегов на главном экране.

| Действие | Как сделать |
|---|---|
| Создать тег | Введите имя в поле **Новый тег**, выберите цвет, нажмите **Создать тег** |
| Переименовать | Значок карандаша ✏ (**Переименовать**) → новое имя → ✓ (**Сохранить название**) |
| Сменить цвет | Значок палитры 🎨 (**Изменить цвет**) → выберите один из 6 цветов |
| Удалить | Значок корзины 🗑 → подтвердите. Тег пропадёт из всех заметок, сами заметки останутся |

Рядом с каждым тегом показано, сколько заметок им помечено. Каждый пользователь видит только свои теги.

## 7. Профиль и выход

Нажмите на кружок с инициалами в правом верхнем углу — откроется меню с вашим именем и логином.
- **Выйти** — завершает сессию на этом устройстве.

## 8. Админ-панель (только для администратора)

У пользователя с ролью «Администратор» в меню профиля есть пункт **Админ-панель** (адрес `/admin`).

- Таблица всех пользователей: **Имя**, **Логин**, **Роль** (Администратор / Пользователь), **Действия**.
- **Удалить пользователя** — значок корзины в строке → подтверждение. Вместе с пользователем безвозвратно удаляются все его заметки и теги.
- Удалить самого себя нельзя (кнопка неактивна).

Обычный пользователь не видит этот пункт, а при попытке открыть `/admin` напрямую возвращается на главный экран.

## 9. Частые вопросы и ошибки

| Сообщение / ситуация | Причина и решение |
|---|---|
| «Логин уже занят» | Выберите другой логин при регистрации |
| «Неверный логин или пароль» | Проверьте раскладку и Caps Lock; используйте 👁, чтобы увидеть пароль |
| «Нет связи с сервером…» | Сервер просыпается после простоя (бесплатный хостинг) — подождите минуту и нажмите **Повторить** |
| «Введите название заметки» | Название — обязательное поле |
| Меня выкинуло на экран входа | Истёк срок сессии (24 ч) — войдите снова |
| Не вижу заметки другого человека | Так и задумано: каждый видит только свои заметки и теги |

## Деплой на бесплатном хостинге

Приложение разворачивается **одним сервисом**: Docker-образ собирает React-фронтенд и запускает FastAPI, который раздаёт и интерфейс, и API на одном адресе. База — бесплатная PostgreSQL.

### Вариант A — Render Blueprint (рекомендуется, всё в один клик)

1. Зарегистрируйтесь на https://render.com через GitHub.
2. **New → Blueprint** → выберите репозиторий `Maslo1911/Metka`.
3. Render прочитает `render.yaml` и создаст:
   - веб-сервис **metka** (Docker, тариф Free);
   - базу **metka-db** (PostgreSQL, тариф Free);
   - `SECRET_KEY` — сгенерируется автоматически.
   - `ADMIN_PASSWORD` — тоже сгенерируется; посмотреть его: сервис **metka → Environment**. Это пароль для входа под логином `admin`.
4. Нажмите **Deploy Blueprint** и дождитесь сборки (5–10 минут). Адрес будет вида `https://metka-xxxx.onrender.com`.

При первом запуске скрипт `backend/app/init_db.py` сам создаёт таблицы и тестовые данные из `schema.sql`, а при каждом старте — выставляет пароль администратора из `ADMIN_PASSWORD`. Повторные запуски данные не трогают.

> ⚠️ Бесплатная PostgreSQL на Render удаляется через 30 дней. Для долгой жизни используйте вариант B.

### Вариант B — Render (веб) + Neon (бессрочная бесплатная PostgreSQL)

1. На https://neon.tech создайте проект и скопируйте **Connection string** (`postgresql://…?sslmode=require`).
2. На Render: **New → Web Service** → репозиторий `Maslo1911/Metka` → Runtime **Docker**, Instance **Free**.
3. В **Environment** добавьте переменные:
   - `DATABASE_URL` — строка из Neon;
   - `SECRET_KEY` — любая длинная случайная строка;
   - `ADMIN_PASSWORD` — пароль для `admin`.
4. **Create Web Service**. Health check path: `/health`.

### Проверка после деплоя

- `https://<адрес>/health` → `{"status":"healthy"}`
- `https://<адрес>/docs` → Swagger
- `https://<адрес>/` → экран входа; зарегистрируйте пользователя или войдите как `admin`.

### Локальный запуск через Docker

```bash
docker build -t metka .
docker run -p 8000:8000 -e DATABASE_URL=postgresql://postgres:postgres@host.docker.internal:5432/metka -e SECRET_KEY=dev -e ADMIN_PASSWORD=admin123 metka
```

Затем откройте http://localhost:8000.
