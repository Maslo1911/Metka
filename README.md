# Название сервиса: Metka

## Запуск приложения

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для production-сборки: `npm run build`.

Это демонстрационный фронтенд на React и Tailwind CSS. Заметки, теги и введённый профиль сохраняются в `localStorage` текущего браузера. Экран входа и регистрации показывает интерфейс макета без сервера и реальной проверки учётных данных. Главный экран доступен сразу; форму входа можно открыть через аватар. Маршруты: `/`, `/notes/new`, `/notes/:id`, `/tags`, `/login`.

# Целевая аудитория

Люди, которым нужно быстро фиксировать мысли, идеи, задачи и информацию, а затем находить их по темам: студенты, фрилансеры, менеджеры, авторы контента — все, кому обычный список заметок без структуры неудобен.

# Главные функции

1. Создание и редактирование заметок (текст, заголовок, дата).
2. Добавление одного или нескольких тегов к заметке.
3. Фильтрация и поиск заметок по тегам.
4. Поиск по тексту заметок.
5. Управление тегами: создание, переименование, удаление, цветовая маркировка.

# Экраны системы

1. **Главный экран** — список всех заметок с превью, панель тегов сверху для быстрой фильтрации, кнопка создания новой заметки.
2. **Экран заметки** — редактирование текста, добавление/удаление тегов, сохранение, дата последнего изменения.
3. **Экран управления тегами** — список всех тегов с количеством заметок в каждом, возможность создать/удалить/переименовать тег, выбор цвета.

# Роли в системе

Админ / пользователь — админ управляет пользователями и модерацией, пользователь работает только со своими заметками и тегами.
