# Название сервиса: Metka

## Запуск приложения

### 1. База данных
Установить PostgreSQL, создать БД `metka` и применить схему:
```bash
psql -U postgres -c "CREATE DATABASE metka"
psql -U postgres -d metka -f backend/schema.sql
```
> ⚠️ Пользователи из тестовых данных `schema.sql` имеют заглушки вместо bcrypt-хэшей, войти под ними нельзя.
> Создайте аккаунт через форму регистрации в приложении (или `POST /api/auth/register`).

### 2. Бэкенд
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env  — и поправить DATABASE_URL / SECRET_KEY
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
Swagger: http://localhost:8000/docs

### 3. Фронтенд — два режима

**Разработка (горячая перезагрузка)** — бэкенд на :8000 запущен, затем:
```bash
cd frontend
npm install
npm run dev
```
Открыть http://localhost:5173. Запросы на `/api` Vite проксирует на `localhost:8000` (см. `vite.config.js`).

**Одним сервером (как в production)** — собрать фронтенд, и FastAPI сам его раздаст:
```bash
cd frontend
npm install
npm run build
```
Затем перезапустить бэкенд и открыть http://localhost:8000 — приложение и API на одном адресе.

Если API размещён на другом домене, задайте в `frontend/.env`: `VITE_API_URL=https://api.example.com`.

# Целевая аудитория

Люди, которым нужно быстро фиксировать мысли, идеи, задачи и информацию, а затем находить их по темам: студенты, фрилансеры, менеджеры, авторы контента — все, кому обычный список заметок без структуры неудобен.

# Главные функции

1. Создание и редактирование заметок (текст, заголовок, дата).
2. Добавление одного или нескольких тегов к заметке.
3. Фильтрация и поиск заметок по тегам.
4. Поиск по тексту заметок.
5. Управление тегами: создание, переименование, удаление, цветовая маркировка.

# Экраны системы

1. **Главный экран** — список всех заметок с превью, панель тегов сверху для быстрой фильтрации, кнопка создания новой заметки.
2. **Экран заметки** — редактирование текста, добавление/удаление тегов, сохранение, дата последнего изменения.
3. **Экран управления тегами** — список всех тегов с количеством заметок в каждом, возможность создать/удалить/переименовать тег, выбор цвета.

# Роли в системе

Админ / пользователь — админ управляет пользователями и модерацией, пользователь работает только со своими заметками и тегами.
